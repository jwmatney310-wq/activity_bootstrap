Viewport

The viewport is the visible area of a webpage in a browser window. Its size depends on the device and the size of the browser window.

Flexbox

Flexbox is a CSS layout method that arranges items in a row or a column. It helps control their alignment, spacing, and size within a container.

Grid

A grid layout arranges content in rows and columns. It helps organize and align different parts of a webpage.
